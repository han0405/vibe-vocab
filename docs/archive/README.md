# Archive — frozen experiment artifacts

These files are kept for provenance only. They are **not** maintained and may
describe an older state of the plugin.

- `PROMPT-OPTIMIZATION-BRIEF.md` — the self-contained brief handed to an
  external model for the one-off prompt-optimization pass.
- `prompt-candidates/` — the six candidate rule prompts that pass compared.
  `checklist-gate-v2` was the winner and its text now lives in
  `rules/vibe-vocab.md`; `persona` is the runner-up kept on file as a fallback.

The outcome, scoring, and residual risks are written up in
`../PROMPT-ITERATION-RESULTS.md`.
