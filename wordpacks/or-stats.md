# Word pack: Operations Research / Optimization / Statistics

Copy this file's contents into `vocab-focus.md` in your project root to put these terms in Active mode.

| Term | Gloss | Meaning |
|---|---|---|
| linear programming | 线性规划 | optimize a linear objective under linear constraints |
| integer programming | 整数规划 | decision variables constrained to integers |
| feasible region | 可行域 | set of points satisfying all constraints |
| objective function | 目标函数 | the quantity being maximized or minimized |
| decision variable | 决策变量 | what the solver is allowed to choose |
| constraint | 约束 | a rule the solution must satisfy |
| slack variable | 松弛变量 | turns an inequality into an equality |
| duality | 对偶 | every LP has a paired problem with matching optimum |
| shadow price | 影子价格 | marginal value of relaxing a constraint |
| relaxation | 松弛 | drop or weaken constraints for an easier bound |
| branch and bound | 分支定界 | tree search with pruning by bounds |
| cutting plane | 割平面 | add constraints that remove fractional solutions |
| convex | 凸 | any local optimum is global; line segment stays inside |
| gradient / subgradient | 梯度 / 次梯度 | slope; generalized slope for non-smooth functions |
| Lagrangian | 拉格朗日函数 | objective plus penalized constraints |
| KKT conditions | KKT 条件 | first-order optimality for constrained problems |
| stochastic | 随机 | involving randomness / probability distributions |
| expected value | 期望 | probability-weighted average outcome |
| variance / standard deviation | 方差 / 标准差 | spread of a distribution |
| confidence interval | 置信区间 | range that covers the parameter at a stated rate |
| hypothesis test | 假设检验 | decide between null and alternative |
| p-value | p 值 | prob. of data this extreme if null were true |
| regression | 回归 | model a response as a function of predictors |
| heteroskedasticity | 异方差 | error variance not constant across observations |
| Monte Carlo | 蒙特卡洛 | estimate by random sampling |
| Markov chain | 马尔可夫链 | next state depends only on the current one |
| queueing theory | 排队论 | math of waiting lines (arrival, service, utilization) |
| greedy algorithm | 贪心算法 | take the locally best step each time |
| dynamic programming | 动态规划 | solve by combining overlapping subproblems |
| NP-hard | NP 难 | at least as hard as the hardest problems in NP |
